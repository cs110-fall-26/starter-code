# Todo List Web App

Today, we will write a web app that loads tasks, save tasks, and allows users to add tasks.

## Together

We will implement the `server.py` file together. Please follow along as we code the server file.

## Tasks

1. In the `util.py`, implement the `load_tasks` and `save_tasks` functions. These will read and write to the `tasks.json` file.
2. `load_tasks` will load the tasks from the file and return the list.
3. `save_tasks` takes in the list of tasks and writes it to the `tasks.json` file.
4. Update the style of the `index.html` to make the page look more appealing.

## Credit

To get full credit, you must have the util functions completed and the `index.html` must have some style attached to it. It must have some design implemented.

## Task

- In your local repository, which should be named `cs110-<username>`, with &lt;username&gt; being your username, an within the "inclass" folder, create another folder named "post-setup". 
- Copy the `hello.py` file from this folder and add it into the "post-setup" folder in your local repository.
- Change the name in the quote of the `name` variable to match your name. Update the age variable to your age.
- Add the missing todo tasks and print out your new variables.

# Simple Notes Web App

This extra credit is much bigger than the previous one.

This extra credit requires you to create your own custom notes web application. Starter code is provided, but it is up to you to add additional routes, views, and any additional files.

The starter code is based on the `to do web app in class` assignment.

## Task

- Build the `index.html` to show notes.
- Add a form in the `index.html` to create a new note
    - The form must include the following inputs: name, description, tags ( separated by commas)
    - The new note form must send to `/api/notes`
- Allow the user to delete a note with a delete button that sends a post request with the name of the note.
    - This should go to `/api/del_note`
- Add the functions to load and save the notes from a json file. (No starter code is given for this feature. You must write this yourself.)

## Grade

To achieve a complete for this, you must complete all of the tasks. Any use of Generative AI or any code not written by yourself is automatically a 0. Tutors and TAs may support, but code written must be original.
